                            ศูนย์การเข้าถึงที่เท่าเทียมและมาตรการคุ้มครองข้อมูล (Accessibility & PDPA)
                        

                        

                            การออกแบบตามมาตรฐาน WCAG 2.1 Level AA และพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562
                        

                    

                

            


            
            

                

                    
                    เกณฑ์การประเมินการเข้าถึงที่เท่าเทียม (Universal Accessibility Checklist)
                


                

                    

                        
                        

                            
1. High Contrast Theme (อัตราส่วนความต่างสี > 7:1)

                            
รองรับผู้มีสายตาเลือนรางด้วยชุดสีดำ-เหลืองความคมชัดสูง

                        

                    

                    

                        
                        

                            
2. Font Size Scaling (ปรับขนาดฟอนต์ 3 ระดับ)

                            
ขยายตัวอักษรได้สูงสุด 20px โดยที่ข้อความไม่ล้นหรือตัดตก

                        

                    

                    

                        
                        

                            
3. Screen Reader Support (Semantic HTML & ARIA)

                            
มี Skip Link, ARIA Labels และ Role กำกับครบทุกส่วน

                        

                    

                    

                        
                        

                            
4. Voice-to-Text Input (พิมพ์ด้วยเสียงภาษาไทย)

                            
เชื่อมต่อ Web Speech API พิมพ์ลงฟอร์มได้โดยไม่ต้องใช้แป้นพิมพ์

                        

                    

                    

                        
                        

                            
5. Keyboard Navigable (การนำทางด้วยแป้นพิมพ์)

                            
แสดง Focus Outline ชัดเจนและกด Tab นำทางได้ทุกปุ่ม

                        

                    

                    

                        
                        

                            
6. Mandatory Alt-Text for Images (คำบรรยายภาพ)

                            
ระบบบังคับใส่คำอธิบายภาพในคลังผลงานเพื่อผู้พิการทางสายตา

                        

                    

                

            


            
            

                

                    
                    มาตรการคุ้มครองข้อมูลส่วนบุคคล (PDPA Notice & Data Control)
                

                

                    ระบบนี้ทำงานแบบ Local-First Storage ข้อมูลทั้งหมดจะถูกจัดเก็บในหน่วยความจำของเบราว์เซอร์บนเครื่องของผู้ใช้เท่านั้น ไม่มีการส่งข้อมูลส่วนบุคคล, รูปภาพ หรือผลงานออกสู่เซิร์ฟเวอร์ภายนอก ผู้ใช้สามารถสำรอง (Export) หรือล้างข้อมูลทั้งหมดได้ตลอดเวลา
