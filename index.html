1. High Contrast Theme (อัตราส่วนความต่างสี > 7:1)

                            
รองรับผู้มีสายตาเลือนรางด้วยชุดสีดำ-เหลืองความคมชัดสูง

3. Screen Reader Support (Semantic HTML & ARIA)

                            
มี Skip Link, ARIA Labels และ Role กำกับครบทุกส่วน

                        

                    

                    

                        
                        

                            
4. Voice-to-Text Input (พิมพ์ด้วยเสียงภาษาไทย)

                            
เชื่อมต่อ Web Speech API พิมพ์ลงฟอร์มได้โดยไม่ต้องใช้แป้นพิมพ์

                        

                    

                    

                        
                        

                            
5. Keyboard Navigable (การนำทางด้วยแป้นพิมพ์)

                            
แสดง Focus Outline ชัดเจนและกด Tab นำทางได้ทุกปุ่ม
